# 4. Editor

## Para qué sirve
Es el espacio de edición del plano y acceso a todas las herramientas técnicas.

## Cómo acceder
Abra un proyecto. Los modos superiores son **Plano**, **Revisión normativa**, **Simulación** e **Informe**.

## Datos que necesita
El editor abre vacío; una imagen de plano es necesaria para el trabajo gráfico real.

## Paso a paso
1. Cargue un plano.
2. Use seleccionar, mover, símbolo, flecha o texto.
3. Organice objetos en capas.
4. Use zoom, centrado, undo/redo y eliminación.

## Controles disponibles
Barra superior, canvas, biblioteca de símbolos, capas, mediciones, Inspector IA y paneles técnicos.

## Qué guarda
Capas, objetos editables, viewport, geometría y cambios manuales. La selección visual es efímera. Zoom, pan y selección geométrica no afectan la vigencia de Advisor.

## Qué no hace
No impide por sí solo ubicar objetos incorrectamente ni valida automáticamente cada cambio.

## Advertencias y limitaciones
Una capa bloqueada evita editar sus elementos. Transformar geométricamente la imagen del plano puede invalidar la escala.

## Errores habituales
Trabajar en herramienta incorrecta, capa bloqueada u objeto fuera de vista.

## Ejemplo práctico
Crear una capa “Señalización”, insertar una salida y ajustar su posición con **Seleccionar**.
