# Caso práctico ficticio: Oficina administrativa de una planta

> Todos los datos son ficticios. El ejemplo no afirma cumplimiento legal.

## 1. Crear proyecto
Nombre: “Oficina administrativa — ejemplo”. Descripción: “Caso de capacitación”. Estado: Borrador.

## 2. Cargar plano
Se carga `oficina-ejemplo.png`, una imagen legible de una sola planta. Se espera **Guardado**.

## 3. Calibrar
Se marcan los extremos de una pared cuya longitud ficticia declarada es 8,40 m. Se verifica el indicador px/m.

## 4. Medir
Se guardan una distancia de circulación, el ancho de dos puertas y el polígono del área administrativa. Cada medición recibe una etiqueta. Los anchos se asocian a sus elementos cuando están disponibles.

## 5. Crear sectores
El área se convierte en “Administración”, tipo oficina, ocupación manual ficticia 10. Se agrega “Pasillo central” desde otra superficie.

## 6. Perfil técnico
Se declaran Argentina, Buenos Aires, actividad oficina, edificio existente, una planta, superficie ficticia y ocupación máxima 10. La procedencia se marca correctamente; no se simula confirmación profesional.

## 7. IA y propuesta
Se ejecuta análisis del edificio. Se revisan habitaciones, puertas, pasillos, salidas y advertencias. En la propuesta se excluye un símbolo dudoso, se corrige una coordenada y se aceptan los restantes.

## 8. Revisión preliminar
Se ejecuta la revisión normativa. Los controles sin datos se conservan como no verificables y se navega la evidencia disponible.

## 9. Simulación
Se configura un escenario normal con 10 ocupantes y parámetros declarados. Luego se duplica y bloquea una salida ficticia. Se comparan resultados como estimaciones, no como prueba de seguridad.

## 10. Advisor
Advisor interpreta perfil, geometría, revisión y escenarios. Se revisan observaciones y se marcan como “En revisión”. Si cambian mediciones, se actualiza el análisis.

## 11. Identidad e informe
Se crea una plantilla ficticia “Consultora Ejemplo”, sin datos reales. Se carga un logo de prueba y se genera el PDF. Antes de cualquier uso externo, el profesional debe revisar plano, datos, fuentes, medidas, resultados y advertencias.

## 12. Respaldo
Se espera **Guardado** y se descarga el bundle JSON.
