# 12. Inteli Advisor

## Para qué sirve
Interpreta resultados ya existentes y produce observaciones técnicas con evidencia y prioridades.

## Cómo acceder
Barra del editor → **Inteli Advisor** → **Analizar Proyecto**.

## Datos que necesita
Consume perfil, mediciones, sectores, rutas, salidas, simulaciones, revisión normativa, análisis del edificio e historial. No vuelve a ejecutar esos motores.

## Paso a paso
1. Ejecute los análisis pertinentes.
2. Abra Advisor y analice.
3. Lea resumen y observaciones.
4. Filtre por texto, prioridad, categoría o estado.
5. Navegue evidencias y cambie estados.
6. Si el proyecto cambia, use **Actualizar análisis**.

## Controles disponibles
Filtros rápidos, búsqueda, estados pendiente/en revisión/resuelta/descartada, evidencia y modos Estándar/Asistida.

## Qué guarda
Fingerprint, versiones 1.1.0/1.0.0, resumen, observaciones, estados, narrativa validada y auditoría.

## Qué no hace
No certifica, aprueba, modifica el plano ni genera hechos nuevos. La redacción asistida sólo reformula.

## Advertencias y limitaciones
Un análisis `stale` es histórico. Una evidencia eliminada puede no localizarse. El modo asistido requiere configuración backend y puede usar fallback estándar.

## Errores habituales
Analizar antes de generar datos, interpretar prioridad como dictamen o usar narrativa desactualizada.

## Ejemplo práctico
Detectar ocupación faltante y concentración de uso de una salida, abrir la evidencia y marcar la observación “En revisión”.
