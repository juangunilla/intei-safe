# 2. Primeros pasos

## Para qué sirve
Describe el acceso inicial y la preparación mínima del entorno de trabajo.

## Cómo acceder
Use la pantalla de inicio de sesión. Tras autenticarse se abre el Dashboard; **Mis Proyectos** contiene la gestión completa.

## Datos que necesita
Correo y contraseña válidos. Para crear un proyecto: nombre obligatorio, descripción y estado opcionales.

## Paso a paso
1. Inicie sesión.
2. Seleccione **Nuevo proyecto** o **Crear proyecto**.
3. Escriba nombre, descripción y estado.
4. Confirme con **Crear proyecto**.
5. Abra el proyecto y espere el estado **Guardado** después de cada cambio.

## Controles disponibles
Navegación principal, buscador, filtros, proyectos recientes, botón de cierre de sesión y selector de vista en tarjetas/lista.

## Qué guarda
La sesión autenticada y los proyectos asociados al usuario. La preferencia tarjetas/lista se conserva localmente en el navegador.

## Qué no hace
No crea automáticamente un plano ni completa información técnica.

## Advertencias y limitaciones
El registro y la gestión administrativa dependen de los permisos configurados. Las funciones del editor requieren conexión con backend y MongoDB.

## Errores habituales
Credenciales inválidas, backend inaccesible o formulario sin nombre de proyecto.

## Ejemplo práctico
Crear “Oficina administrativa — Planta baja”, estado **Borrador**, y abrirlo desde la tarjeta generada.
