# 18. Preguntas frecuentes

## ¿Inteli PDE certifica cumplimiento?
No. La revisión es preliminar y requiere profesional competente.

## ¿La IA modifica el plano automáticamente?
El análisis guarda resultados; una propuesta sólo modifica el plano al pulsar **Aceptar propuesta**.

## ¿Puedo medir sin escala?
Sí, en píxeles. Metros y m² requieren calibración.

## ¿Qué se guarda automáticamente?
El bundle completo del editor cuando el estado llega a **Guardado**.

## ¿Guardar proyecto es el autoguardado?
No. Ese botón descarga un JSON local.

## ¿Qué significa “no verificable”?
No existen datos suficientes para evaluar ese control; no significa cumplimiento.

## ¿Advisor vuelve a ejecutar otros motores?
No. Interpreta resultados guardados.

## ¿La simulación reemplaza un simulacro?
No. Es estimativa.

## ¿Puedo tener varias plantillas?
Sí, dentro del proyecto; no se comparten entre proyectos.

## ¿Qué hago ante Error al guardar?
Mantenga abierta la pestaña, compruebe backend/conexión y descargue un JSON de respaldo.

## Ejemplo práctico
Si Advisor aparece desactualizado después de medir una salida, pulse **Actualizar análisis**; no necesita repetir simulación o normativa salvo que sus propios datos hayan cambiado.
