# 19. Glosario

- **Advisor:** intérprete determinístico de resultados existentes.
- **Análisis del edificio:** detecciones estructuradas obtenidas desde la imagen.
- **Asset:** imagen reutilizable, como plano, logo, firma o sello.
- **Autoguardado:** persistencia diferida en backend.
- **Bundle:** JSON completo exportable del proyecto.
- **Calibración:** relación entre distancia en píxeles y metros reales.
- **Canvas:** área gráfica editable.
- **Capa:** agrupación visible/bloqueable de objetos.
- **Context fingerprint:** huella estable usada para determinar vigencia de Advisor.
- **Evidencia:** referencia trazable a medición, sector, ruta, elemento, simulación o regla.
- **Medición persistente:** entidad de distancia, ancho o área guardada.
- **No verificable:** estado por información insuficiente.
- **Perfil técnico:** datos declarados del establecimiento y su procedencia.
- **Propuesta:** conjunto de objetos IA todavía no aplicado.
- **Ruta:** flecha o recorrido asociado a origen/salida.
- **Sector:** polígono funcional con tipo, área y ocupación opcional.
- **Simulación:** cálculo estimativo determinístico de un escenario.
- **Stale/Desactualizado:** resultado generado con contexto o versión anterior.
- **Template corporativo:** identidad visual seleccionable del informe.
- **Viewport:** zoom y desplazamiento actual del canvas.

Los términos de resultado no representan certificación ni aprobación legal.
