# 3. Proyectos

## Para qué sirve
Organiza documentos de trabajo independientes y sus estados.

## Cómo acceder
Barra superior → **Mis Proyectos**.

## Datos que necesita
Nombre (máximo 120 caracteres), descripción (máximo 1000) y estado disponible en el selector.

## Paso a paso
1. Cree o localice un proyecto.
2. Use búsqueda, estado y orden.
3. Cambie entre tarjetas y lista.
4. Use **Abrir**, **Editar**, **Duplicar** o **Eliminar**.

## Controles disponibles
Crear, buscar, filtrar, ordenar, vista tarjetas/lista y menú de acciones.

## Qué guarda
Metadatos, miniatura, estado completo del editor y `documentVersion` para control de concurrencia.

## Qué no hace
Duplicar no recalcula análisis ni actualiza datos técnicos.

## Advertencias y limitaciones
Eliminar es irreversible desde la interfaz. Una edición basada en una versión antigua puede producir conflicto 409.

## Errores habituales
“No se pudieron cargar los proyectos”, nombre vacío, conflicto de versión o error al duplicar/eliminar.

## Ejemplo práctico
Duplicar un proyecto antes de ensayar una variante de distribución y renombrar la copia.
